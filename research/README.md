# Research notes

Exploratory work behind the pivot decomposition: plain Python with no dependency on Lean, and not
part of the Lean build.

| path | contents |
|---|---|
| [`experiments/`](experiments/README.md) | Numerical exploration of CNOT-count improvements over Block-ZXZ: a reference Block-ZXZ implementation, the pivot construction (`foldzxz_opt.py`), its benchmark, and the other levers tried, with their outcomes |
| [`supplementary.tex`](supplementary.tex) | Supplement *The balanced-split pivot: implementation and experiments*: the search for the pivot angles, the benchmark, and figures |
| `figures/` | Figures and data for the supplement, generated by `experiments/balanced_figs.py` (git-ignored) |
| [`movie/`](movie/) | A Manim explainer video of the pivot (`pivot.py`, data from `data.py`, rendered by `render.sh`) |

Run the scripts from inside their directory, e.g. `cd experiments && python3 zxz.py`. They need
NumPy and SciPy; the figures need Matplotlib, and the video needs Manim, LaTeX with `dvisvgm`, and
`ffmpeg`.
